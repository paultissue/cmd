Chatbot Provider Prefix & Shortcut Aliases

The !! shortcut alias can be used in place of !cmd on supported chatbot providers: StreamElements, Nightbot, Fossabot, Streamlabs Cloudbot, and Streamer.bot. Not supported on: KickBot.

Command Modifiers

Append a hyphen (-) to display only the first URL, or a pipe (|) to truncate the output after the first URL block.

Shout-out Modifiers

Modifier Suffix Behavior Description Example Command
- (Minus) Displays only the first URL found in the response. !cmd cs-
| (Pipe) Truncates the response at the second pipe character (stops after the first URL block). !cmd cs|

Shout-out Examples

Command Example Resulting Output
!cmd cs 📢 Chris Sims 🇺🇸 | 📺 https://youtube.com/@ChrisxSims | 💬 https://x.com/ChrisxSims | 💸 https://cash.app/ChrisxSims
!cmd cs| 📢 Chris Sims 🇺🇸 | 📺 https://youtube.com/@ChrisxSims
!cmd cs- https://youtube.com/@ChrisxSims

Trivia Commands Reference (!cmd q / !cmd a / !cmd q2 / !cmd a2)

The trivia system provides random trivia questions and retrieves stored answers per user and channel context.

1. Command Overview

Command Aliases Description
!cmd q q, q1, trivia, question, trivia1, question1 Fetches a random trivia question from The Trivia API.
!cmd a a, a1, answer, answer1 Retrieves the answer for the active !cmd q question.
!cmd q2 q2, trivia2, question2 Fetches a random trivia question from OpenTDB (with fallback to Trivia API).
!cmd a2 a2, answer2 Retrieves the answer for the active !cmd q2 question.

2. Command Modifiers (Difficulty)

Suffixing q or q2 with a modifier explicitly selects the difficulty tier. Unmodified commands select a random difficulty.

Modifier Suffix Difficulty Emoji Example Command
- (Minus) Easy 🟢 !cmd q- or !cmd q2-
| (Pipe) Medium 🟡 !cmd q| or !cmd q2|
! (Exclamation) Hard 🔴 !cmd q! or !cmd q2!

4. Example Invocations

Command Invocation Description
!cmd q Request a random Trivia API question (random difficulty, any category).
!cmd q- history Request an Easy history question from Trivia API.
!cmd q! sci Request a Hard science question from Trivia API.
!cmd a View the answer to the last requested Trivia API question.
!cmd q2| geo Request a Medium geography question from OpenTDB.
!cmd a2 View the answer to the last requested OpenTDB trivia question.
