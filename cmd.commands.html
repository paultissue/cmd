Command Usage

Use !cmd to invoke these shout-out service commands. The !! shortcut alias can be used in place of !cmd on supported providers.

🤖 Usage: !cmd <command> [args]
🤖 Usage: !! <command> [args]

Syntax Parameters & Format

Element Description
<command> You must provide a specific command to invoke.
[args] Optional and only provided if the specific command requires them.
Format There must be a space after !cmd or !! before the specific command to invoke.

Example Command Response Output
!! likes 123 👍 123 Thumbs Up 👍 Smash that Like button! 👍 Let's Goooo! 🇺🇸

!cmd answer2 💡 Answer2: Sweet Jane

Command Modifiers

Append a hyphen (-) to display only the first URL, a pipe (|) to truncate the output after the first URL block, or an exclamation mark (!) for the full unmodified response.
There must be no space between the command and the modifier itself.

Shout-out Modifiers

Command Example Modifier Suffix Behavior Description
!cmd ht- - (Minus) Displays only the first URL found in the response.
!cmd ht| | (Pipe) Truncates the response at the second pipe character (stops after the first URL block).
!cmd ht! ! (Exclamation) Displays the full unmodified response (large/default output).

Trivia Commands Reference (!cmd q / !cmd a -and- !cmd q2 / !cmd a2)

The trivia system provides random trivia questions and retrieves stored answers per user and channel context.

1. Command Overview

Command Example Aliases Description
!cmd q q, q1, trivia, question, trivia1, question1 Fetches a random trivia question from The Trivia API.
!cmd a a, a1, answer, answer1 Retrieves the answer for the active !cmd q question.
!cmd q2 q2, trivia2, question2 Fetches a random trivia question from OpenTDB (with fallback to Trivia API).
!cmd a2 a2, answer2 Retrieves the answer for the active !cmd q2 question.

2. Command Modifiers (Difficulty)

Suffixing q or q2 with a modifier explicitly selects the difficulty tier. Unmodified commands select a random difficulty. Answer commands (!a / !a2) do not require a difficulty modifier to return the answer. Invoking !q or !q2 again for the same user overwrites the previous active question's answer, so !a or !a2 only returns the answer to the most recent question. !a and !a2 track their answers independently.

Command Example Modifier Suffix Difficulty Emoji
!cmd q- or !cmd q2- - (Minus) Easy 🟢
!cmd q| or !cmd q2| | (Pipe) Medium 🟡
!cmd q! or !cmd q2! ! (Exclamation) Hard 🔴

Command Invocation Description

Response URL Parameter Settings

The response URL parameter (aliases: r, resp, response) overrides the default behavior of commands that do not include a command modifier. If not specified, response defaults to large. Note that this is not a user setting, but rather a customization that some channels may opt-in to.

Response Value Aliases Mapped Modifier Behavior Description
small small, sm, s - (Minus) Displays only the first URL found in the response.
medium medium, md, m | (Pipe) Truncates the response at the second pipe character (stops after the first URL block).
large large, lg, l ! (Exclamation / Default) Displays the full unmodified response (default when response is not specified).
